# 需求补充 — 电路元件网格化（用户裁定 2026-10-17）

> 状态：已接受，纳入 V1 需求基线。影响 P4（`ui/circuit_scene.py`），对 P0–P3 内核无影响。

## 1. 需求内容

1. **元件网格化**：所有元件（电池/电阻/灯泡/开关/电表）摆放位置吸附到统一网格（grid snap），不可任意像素落点。
2. **导线 8 向化**：网格化之后，导线方向减少至 8 向 —— 上、下、左、右 + 四条对角线（即 `dx, dy ∈ {-1, 0, 1}` 且不同时为 0 的 8 个方向）。
3. 目的：降低开发难度与 bug 率（碰撞、吸附、连线判定都从"任意角度线段"退化为"格点 + 8 向"）。

## 2. 与现有红线的边界（重要）

需求书 10.3 红线：「电学连通只用图论 node id 计算，禁止碰像素坐标」。本补充与红线的分工：

| 层 | 职责 | 是否允许坐标 |
|---|---|---|
| UI 画布层（P4） | 网格吸附、8 向导线路径绘制、端点→节点归属 | ✅ 允许（仅限本层） |
| 拓扑层（P1 `core/topology.py`） | node id 合并、邻接表 | ❌ 禁止 |
| 求解层（P2/P3） | MNA 组装与求解 | ❌ 禁止 |

- 网格坐标只作为**画布层的交互事实**；导线每段端点落到格点后，归属到 node id，随后即与坐标脱钩。
- 一条视觉上的斜导线（8 向之一）与折线导线在拓扑层等价：都是"两端点之间的导通连接"，由导线合并节点吸收。

## 3. 实现约定（P4 落地时遵循）

- 网格常量：`GRID_SIZE`（建议 20px，P4 定稿可调）；元件引脚必须落在格点上。
- 元件朝向：允许 8 向中的主轴 4 向摆放（横/竖 + 可选对角），V1 建议仅横/竖 2 向以进一步压 bug 率，对角朝向留待后续。
- 导线交互：按下格点 A → 拖到格点 B，自动生成 **8 向折线**（如需 L 形/对角组合自动拆段）；每段一个 wire 元件，端点即节点。
- 导线合法性校验：只接受 8 向直线段，其余输入拒绝并提示（不开后门放行任意角度）。
- 已有 P1 拓扑接口不变：wire 元件仍是 `{"type": "wire", "nodes": [a, b]}`，只是 a、b 的**画布坐标**满足网格与 8 向约束。

## 4. 验收补充（并入硬 Case 列表）

5. **网格吸附**：拖放元件后落点必为格点（无亚像素偏移）。
6. **8 向导线**：非 8 向连线输入被拒绝；8 向连线生成的 wire 元件端点归属正确（拓扑测试可复用现有 `test_wire_merge` 路径）。
