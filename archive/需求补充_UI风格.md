# 需求补充 — UI 风格：护眼绿 + 学生友好（用户裁定 2026-10-17）

> 状态：已接受，纳入 V1 需求基线。影响 P4（`ui/circuit_scene.py`）与 P5（`ui/main_window.py`），对内核 P0–P3 无影响。

## 1. 需求内容

1. **护眼绿底色**：画布与主界面背景使用护眼绿系，降低长时间使用的视觉疲劳。
2. **界面整体学生友好**：面向初高中学生的低门槛交互——大按钮、清晰符号、即时状态反馈、错误提示可读。

## 2. 设计约定（P4/P5 落地时遵循）

| 项 | 约定 |
|---|---|
| 画布底色 | 护眼绿 `#C7EDCC`（主选，可在 P4 定稿微调同色系） |
| 主窗口底色 | 同色系浅绿或白绿过渡，避免纯白刺眼 |
| 网格点/线 | 比底色深一档（如 `#B0D5B8`），低调不抢焦点 |
| 元件符号 | 深灰/黑描边 `#2d2d2d`，线宽 ≥2px，保证投影仪可读 |
| 状态色 | 灯亮=暖黄高亮；短接警告=红字 `#c0392b`（红线要求）；悬空节点=灰色（需求书 4.4） |
| 交互 | 元件拖拽网格吸附（见需求补充_网格化）；开关闭合/断开可点击切换；双击元件弹出简易属性面板（初中仅显示必要属性） |
| 提示文案 | 中文、面向学生口吻，如"开关闭合了""电源被短路了，请检查连线"；错误不使用术语堆砌 |
| 字体 | 系统默认 UI 字体，读数用等宽数字便于对齐 |

## 3. 与现有红线/需求的关系

- 护眼绿仅是视觉层，不改变任何电气语义；短接红字提示（需求书 10.3）颜色上仍用红色系，与绿色底对比足够醒目。
- 学生友好不降低内核精度要求：读数按求解值显示，阈值状态判定（|I|>1e-6、P>0.01W）不变。
- "导入习题"菜单仍按二阶段规划置灰。
